spotlight

Move the mouse over the logos at the bottom of each footer: a circle of light follows it. The logo is written once; the script lays a lit copy over it and opens it only around the pointer — and keeps it there while the page scrolls. On a touch screen there is no pointer, so no light: the logos are hidden there — all but Baibars, which asks to stay (data-pg-spotlight-touch).
